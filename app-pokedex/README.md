Pokedex

Aplicacion web que consume la PokeAPI para mostrar informacion de Pokemon en formato de tarjetas, con buscador y filtros por tipo.

Descripcion

El proyecto presenta una cuadricula de tarjetas, cada una con imagen, numero, nombre, tipos, medidas, habilidades y estadisticas base del Pokemon. Incluye una barra de busqueda y botones de filtro para mostrar Pokemon segun su tipo (fuego, agua, planta, electrico, entre otros).

Estructura del proyecto
proyecto/
├── index.html
├── style.css
└── script.js
Tecnologias utilizadas
HTML5
CSS3 (variables CSS, Flexbox, Grid)
JavaScript
PokeAPI
Caracteristicas
Cuadricula de tarjetas responsive mediante CSS Grid.
Buscador de Pokemon por nombre.
Filtros por tipo de Pokemon.
Tarjetas con imagen, numero, nombre, tipos, medidas, habilidades y estadisticas base.
Barras de progreso visuales para representar las estadisticas.
Diseno adaptado a distintos tamanos de pantalla.
Uso
Clonar o descargar el repositorio.
Abrir el archivo index.html en un navegador web.
Escribir el nombre de un Pokemon en la barra de busqueda o seleccionar un tipo para filtrar los resultados.

No requiere instalacion de dependencias ni servidor local para su funcionamiento basico.

Estilos

El archivo style.css centraliza los colores principales de la interfaz mediante variables CSS definidas en :root, lo que facilita mantener consistencia visual y realizar cambios de color de forma centralizada. Cada tipo de Pokemon cuenta con su propio color de fondo, aplicado tanto en los botones de filtro como en las etiquetas de tipo dentro de las tarjetas.
