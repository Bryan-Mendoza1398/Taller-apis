Taller APIs

Repositorio que agrupa una serie de ejercicios practicos enfocados en el consumo de APIs publicas mediante JavaScript. Cada ejercicio es un proyecto independiente, ubicado en su propia carpeta.

Contenido del repositorio
taller-api/
├── app-pokedex/
├── galeria-api/
└── clima-api/
Proyectos
App Pokedex

Aplicacion que consume la PokeAPI para mostrar informacion de Pokemon en formato de tarjetas, con buscador por nombre y filtros por tipo.

Carpeta: app-pokedex/

Tecnologias: HTML, CSS, JavaScript, PokeAPI

Galeria API

Galeria de imagenes obtenidas mediante el consumo de una API publica.

Carpeta: galeria-api/

Tecnologias: HTML, CSS, JavaScript

Clima API

Aplicacion que consulta una API del clima para mostrar informacion meteorologica segun la ubicacion o ciudad ingresada por el usuario.

Carpeta: clima-api/

Tecnologias: HTML, CSS, JavaScript

Objetivo del repositorio

Este repositorio fue creado con fines de aprendizaje y practica, con el objetivo de reforzar conceptos como el consumo de APIs mediante fetch, el manejo de datos en formato JSON, la manipulacion del DOM y el maquetado con HTML y CSS.

Uso

Cada proyecto es independiente y puede ejecutarse por separado. Para probarlo:

Ingresar a la carpeta correspondiente al ejercicio deseado.
Abrir el archivo index.html (o el archivo principal del proyecto) en un navegador web.

No se requiere instalacion de dependencias ni servidor local para el funcionamiento basico de los proyectos.
